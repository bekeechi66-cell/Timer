vMix / NDI Setup

  1. Click Output above to enter the clean full-screen timer.
  2. In vMix: Add Input → Web Browser, enter this page's URL and append ?view=output.
  3. Set the input to 1024×576 or higher and enable Transparent if you selected the Clear background.
  4. Open Output → NDI on that input (or the main output) to send the timer across the network.
  5. Control it live from an Android phone using the QR code above — or press Space to start/pause, R to reset, F for fullscreen.
